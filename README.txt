JUMPING ANIMALS - Juego con three.js

TEMATICA

Dos niveles infinitos que se generan mientras avanzas. Cada fila nueva
suma un punto y la dificultad sube con la distancia. Si pierdes, el
mundo se reinicia. El record de cada nivel se guarda en el navegador.

Nivel 1 - La carretera: una gallina cruza carreteras y esquiva carros.
Nivel 2 - El rio: una rana salta de tronco en tronco. Si cae al agua o la corriente la saca de la zona, pierde.

CONTROLES

Flechas o WASD  Mover (un paso por pulsacion)
Enter / Espacio Reintentar (en Game over)
Esc             Volver al menu

COMO EJECUTAR

Se necesita la extension "Live Server"
VS Code: clic derecho en index.html -> Open with Live Server
